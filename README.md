# Software Factory Plugin

This repository publishes the Software Factory plugin for coding agents. The
plugin equips agents to use the Software Factory MCP effectively and guides
them through reliable, traceable Work Order execution in any repository.

Install the skill with the Skills CLI:

```bash
npx skills add 8090-inc/software-factory-plugin --skill software-factory
```

The plugin source lives in [`plugins/software-factory`](plugins/software-factory),
and its README explains how the plugin works. The original marketplace template
README is preserved at [`docs/template-readme.md`](docs/template-readme.md).

This repository is based on
[mike-north/ai-plugin-marketplace-template](https://github.com/mike-north/ai-plugin-marketplace-template).
