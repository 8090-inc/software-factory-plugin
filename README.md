# Software Factory Plugin

```bash
npx skills add 8090-inc/software-factory-plugin --skill software-factory
```

Software Factory is a portable coding-agent plugin for writing requirements,
blueprints, and work orders, then executing work orders through a repeatable
implementation, review, and verification workflow.

The plugin source lives in [`plugins/software-factory`](plugins/software-factory).
The original marketplace template README is preserved at
[`docs/template-readme.md`](docs/template-readme.md).

This repository is based on
[mike-north/ai-plugin-marketplace-template](https://github.com/mike-north/ai-plugin-marketplace-template).
