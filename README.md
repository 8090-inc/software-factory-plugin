# Software Factory Plugin

```bash
npx skills add 8090-inc/software-factory-plugin --skill software-factory
```

Skills for coding agents to use the 8090 Software Factory: guides for
requirements and blueprints, work order authoring, and repeatable work order
execution with checklists, context files, implementation plans, review, and
verification in any repository, with optional MCP for a hosted Software Factory.

Software Factory also includes empty MCP configuration files for teams that want
to connect their own Software Factory or project tools.

The plugin source lives in [`plugins/software-factory`](plugins/software-factory).
The original marketplace template README is preserved at
[`docs/template-readme.md`](docs/template-readme.md).
